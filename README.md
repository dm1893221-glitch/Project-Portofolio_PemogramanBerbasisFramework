## 📖 Tentang Proyek

Website portofolio personal ini dirancang untuk menampilkan profil profesional, riwayat pendidikan, keahlian teknis (*tech stack*), dan daftar proyek yang telah dikerjakan. Website ini dibangun agar responsif dan nyaman diakses di berbagai perangkat.

---

## ✨ Fitur Utama

* 🏠 **Halaman Beranda / Home**: Sambutan interaktif dan perkenalan singkat.
* 👨‍💻 **Tentang Saya / About**: Informasi detail mengenai latar belakang dan keahlian (*skills*).
* 💼 **Portofolio / Proyek**: Daftar proyek pilihan lengkap dengan teknologi yang digunakan.
* 📬 **Kontak**: Formulir atau tautan langsung untuk terhubung dengan saya.

## Menjalankan aplikasi

Pasang dependensi:

```bash
npm install
```

Jalankan server pengembangan:

```bash
npm run dev
```

Buat build produksi dan jalankan pratinjau:

```bash
npm run build
npm run preview
```

Periksa kode dengan ESLint:

```bash
npm run lint
```
