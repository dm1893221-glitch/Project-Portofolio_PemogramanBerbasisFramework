# Portofolio Danis

Portofolio ini dibuat dengan React, Vite, TypeScript, Tailwind CSS, dan Lucide React.

## Menjalankan aplikasi

Pasang dependensi:

```bash
npm install
```

Jalankan server pengembangan:

```bash
npm run dev
```

Buat build produksi dan jalankan pratinjau:

```bash
npm run build
npm run preview
```

Periksa kode dengan ESLint:

```bash
npm run lint
```
