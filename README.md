## 📖 Tentang Proyek

Website portofolio personal ini dirancang untuk menampilkan profil profesional, keahlian teknis, dan daftar proyek yang telah dikerjakan. Website ini dibangun agar responsif dan nyaman diakses di berbagai perangkat.

---

## ✨ Fitur Utama

* 🏠 **Halaman Beranda / Home**: Sambutan interaktif dan perkenalan singkat.
* 👨‍💻 **Tentang Saya / About**: Informasi detail mengenai latar belakang dan keahlian (*skills*).
* 💼 **Portofolio / Proyek**: Daftar proyek pilihan lengkap dengan teknologi yang digunakan.
* 📬 **Kontak**: Formulir atau tautan langsung untuk terhubung dengan saya.

---

## 💻 Teknologi yang Digunakan

* **React JS** (Library utama untuk membangun antarmuka pengguna)[cite: 2]
* **Vite** (Build tool yang cepat)
* **Tailwind CSS** / CSS (Untuk styling tampilan)

## Menjalankan aplikasi

Pasang dependensi:

```bash
npm install
```

Jalankan server pengembangan:

```bash
npm run dev
```

Buat build produksi dan jalankan pratinjau:

```bash
npm run build
npm run preview
```

Portofolio ini dibuat dengan React, Vite, TypeScript, Tailwind CSS, dan Lucide React.
